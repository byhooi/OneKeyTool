# OneKeyTool — 键盘自定义键改造工具

把键盘上那个"一按就打开 `http://oneclick.lenovo.com.cn`"的按键，改成你想要的功能。

> **无需安装** · **不改固件** · **随时可退** · **默认不碰注册表**

---

## 问题背景

不少联想键盘上有个"一键上网"键，按下去会自动打开 `oneclick.lenovo.com.cn`。

但有意思的是：**这跟联想软件没关系**。我用抓包工具实测分析后发现——

> 是**键盘固件自己**在键盘通道上"敲"出了整个网址。

按下那个键时，固件会模拟出这样一串动作：

```
Win↓  R↓  Win↑  R↑          ← 约 12 毫秒内完成，用于唤起"运行"对话框
  ↓ 约 90 毫秒
h t t p : / / o n e c l i c k . l e n o v o . c o m . c n
  ↓ 约 1.1 秒
回车                          ← "运行"对话框据此打开网页
```

**关键特征**：这些字符的输入间隔是 **0.03~15 毫秒**，而人类打字最快也要 **60 毫秒以上**——差了两个数量级。

**这反而是好消息**：走标准键盘通道，意味着**软件层可以完整拦截改写**，不用改固件、不用拆键盘。

## 功能

按那个自定义键，可以做：

| 动作 | 说明 | 参数示例 |
|---|---|---|
| **打开网址** | 按一下就打开你指定的网页 | `https://www.bing.com` |
| **运行程序** | 启动软件、打开文档、打开文件夹 | `C:\Windows\System32\notepad.exe` |
| **发送快捷键** | 模拟按一组快捷键 | `Ctrl+Alt+S`、`Win+Shift+S` |
| **什么都不做** | 只屏蔽原网址 | — |

## 下载使用

1. 到 [Releases](../../releases) 下载 `OneKeyTool-*-win-x64.zip`
2. **解压到任意文件夹**（建议放文档或桌面，不要放 `Program Files`，否则配置写入可能受限）
3. 双击里面的 `OneKeyTool.exe`，**设置窗口会直接打开**
4. 点「最小化到托盘」或点窗口右上角的 ×，程序就收进**系统托盘**（右下角）；此后双击托盘图标可再打开设置窗口

首次启动会在 exe 同目录自动生成 `config.ini`，之后改配置就改它。

**环境要求**：Windows 10 / 11（64 位）。系统自带的 .NET Framework 4.0 就够，**无需安装任何运行库**。

> **为什么发的是压缩包而不是单个 exe？**
> 浏览器下载裸 `.exe` 时会弹「这种文件可能会损害你的计算机」，
> 下载 `.zip` 不会。这是发压缩包的主要好处。
>
> 但请注意：**用资源管理器解压时，Windows 会把「来自网络」的标记传给解压出的
> exe**，因此首次运行仍可能看到一次 SmartScreen 的「Windows 已保护你的电脑」。
> 这是 Windows 对未签名程序的默认行为，不是报毒。处理办法见
> [首次运行被拦](#首次运行被-smartscreen-拦了怎么办)。
> 若不想看到它，改用 7-Zip / WinRAR 等工具解压（它们不传播该标记）。

### 首次使用：先验证，再启用

程序默认处于**观察模式**——只识别、不拦截，原网址仍会照常打开。

1. **按几次那个自定义键**，看设置窗口里"已触发"计数是否跟着 +1
2. 顺便正常打字、按 Win 键、用 Win+R，确认计数**不会**乱涨
3. 确认没问题后，**取消勾选"观察模式"** → 点"保存并应用"

从此按那个键，原网址不再打开，直接执行你设定的动作。

## 安全性

这个工具需要安装**低级键盘钩子**，所以有几点值得说清楚：

**它不做什么**
- **完全不联网**。程序不含任何网络代码（没有 `System.Net` 引用，可自行反编译核对），
  不会检查更新、不上报、不请求任何服务器。唯一的网络入口是设置窗口右上角
  版本号链接里的「项目主页 / 下载」——那只是调 `Process.Start` 打开你的默认浏览器，
  程序自身不发起任何连接。
- 不装驱动、不改键盘固件
- 不记录你的按键内容
- 默认不写注册表（只有你主动勾选"开机自动启动"时，才会在
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入一条自启项，
  取消勾选即删除）

**识别与恢复行为**（构建时会运行状态机回归用例）：

| 场景 | 结果 |
|---|---|
| 单独按 Win 键 | 超时后原样放行，开始菜单正常弹出 |
| Win+E 等其他组合键 | 检测到后立即放行 |
| 手动按 Win+R | 按键顺序与宏相反，正确放行 |
| 正常打字（间隔 60ms 以上） | 时序不符，放行 |
| 方向键连按 | 不匹配，放行 |
| 长按 Win 键 | 检测到自动重复后立即放弃并恢复暂扣事件 |
| 宏收集途中按住某键 | 达到事件上限即放弃并恢复，不会无界暂扣 |

**兜底机制**：万一程序卡死导致键盘异常，用任务管理器结束 `OneKeyTool.exe` 即可，键盘立刻恢复。程序退出后会卸载钩子，**键盘不会有任何残留状态**。

**想彻底停用**：托盘图标右键 → 退出。

**关于 `onekeytool.log`**

程序会在 exe 同目录写一个 `onekeytool.log`，记录启停、识别命中、异常等运行信息，
方便排查问题。几点说明：

- **不记录你敲了什么**。默认只写"键盘钩子已安装""识别到自定义键"这类事件，
  不含按键内容。只有把 `config.ini` 里的 `DebugKeys` 手动改成 `true`，
  才会记录原始按键（键码、扫描码），默认关闭。
- 日志**不会自动删除**，超过 2MB 会轮转成 `onekeytool.log.1`（旧的被覆盖）。
- 不想要它，直接删掉文件即可，程序下次启动会重新建一个。
- 程序**不会**把日志发往任何地方（见上文「完全不联网」）。

### 首次运行被 SmartScreen 拦了怎么办

双击 `OneKeyTool.exe` 时可能看到蓝色的「Windows 已保护你的电脑」窗口，
提示发布者为「未知发布者」。**这不是报毒**，是 Windows 对所有未做数字签名的
程序的默认处理。程序未购买代码签名证书，所以会有这一步。

两种走法，任选其一：

**方法一：点过去（一次性）**
1. 点窗口里的「**更多信息**」
2. 点右下角出现的「**仍要运行**」

同一台机器上只需做一次，之后直接双击即可。

**方法二：先解除标记（推荐，更干净）**
1. 右键 `OneKeyTool.exe` → **属性**
2. 在「常规」页底部若看到「安全：此文件来自其他计算机，可能被阻止以帮助保护该计算机」，
   勾选旁边的「**解除锁定**」
3. 点「确定」，再双击运行

如果属性页里**没有**那段「安全」提示，说明文件没带网络标记，
也就不会触发 SmartScreen，直接双击即可。

**方法三：改用 7-Zip / WinRAR 解压**
这些工具解压时不传播「来自网络」标记，解出来的 exe 不带标记，运行时不检查。

> 想从根上消除提示，只能给程序做数字签名（需购买 OV/EV 证书）。
> 本项目是个人开源工具，没有做。你若在意，可以从源码自行编译——
> 自己编译出的 exe 不带网络标记，不会有任何提示。

## 工作原理

程序安装一个低级键盘钩子（`WH_KEYBOARD_LL`），用**状态机 + 时序特征**识别：

```
看到 Win↓
   ├─ 先"暂扣"不发给系统，开始观察
   ├─ 80ms 内没有后续           → 判定你自己按 Win，原样放行
   └─ 出现 R
        ├─ 250ms 内首字符不是 h   → 不是宏（如你手动 Win+R），放行
        └─ 收到 h → 进入宏收集
             ├─ 校验前缀 "http" 与特征串 "oneclick"
             ├─ 见到回车且特征齐全  → ★ 命中：丢弃整段宏，执行你的动作
             └─ 超时 / 不符        → 放弃拦截，把暂扣的按键原样重放
```

**观察模式与拦截模式共用同一个状态机**（`src/MacroEngine.cs`）：观察模式只是不吞事件、不执行动作，识别逻辑完全相同。因此观察模式下验证通过，切到拦截模式后行为必然一致。这条性质由构建时的回归用例保证。

**防递归**：程序注入的按键带 `dwExtraInfo` 魔数标记，钩子无条件忽略，因此"放弃拦截 → 重放"的过程不会自我循环。

**防卡键**：暂扣事件数有硬上限（400），超限或超时都会立即放弃拦截并原样重放；退出、重载配置时也会先把暂扣的按键放行。

## 自定义配置

设置窗口能改大部分选项。想改更细的参数，直接编辑 `config.ini`（和 exe 同目录）：

| 键 | 说明 |
|---|---|
| `Enabled` | 总开关 |
| `ActionType` | `url` / `program` / `hotkey` / `none` |
| `ActionValue` | 动作参数 |
| `DryRun` | 观察模式，`true` 时只识别不拦截 |
| `SuppressWindowsKey` | 是否连 Win 键一起拦（推荐 `true`，避免闪"运行"对话框） |
| `WinWaitMs` | 按 Win 后等待时长，默认 `80` 毫秒 |
| `WinUpWaitMs` / `RWaitMs` | 后续两跳的等待时长，一般无需修改 |
| `MacroTimeoutMs` | 整个宏序列的最长时长，默认 `4000` 毫秒 |
| `DebugKeys` | 是否记录原始按键事件，默认关闭 |
| `Signature` | 宏网址中的识别特征，默认 `ONECLICK`，仅支持英文字母和数字 |

改完点"保存并应用"，或托盘菜单选"重新加载配置"。

## 开机自动启动（可选）

程序**不会**擅自设置自启，默认关闭。想开机自动运行，二选一：

**方法一：在界面里勾选**
在设置窗口勾选"开机自动启动" → 点"保存并应用"；
或右键托盘图标，勾选菜单里的"开机自动启动"。取消勾选即关闭。

**方法二：手动放快捷方式**
1. 按 `Win+R`，输入 `shell:startup`，回车
2. 把 `OneKeyTool.exe` 的**快捷方式**拖进打开的文件夹

取消就把快捷方式删掉。

> 方法一写入的是当前用户的 `HKCU\...\Run` 项，**不需要管理员权限**。
> 若把程序移到别处，下次启动时自启项里的路径会自动更新为新位置。

## 升级

程序**不联网、不自动更新**，升级是手动的：

1. 到 [Releases](../../releases) 下载新版 `OneKeyTool-*-win-x64.zip`
2. 解压后，用新的 `OneKeyTool.exe` 覆盖旧的那个
3. `config.ini` 是你的配置，**不会被覆盖**，无需重新设置

点设置窗口**右上角的版本号**会弹出「关于」，里面有项目主页与下载页面的链接。

> 不做自动更新的原因：自动更新需要程序在后台联网、下载并替换自身，
> 这条链路本身会引入新的攻击面（下载源被篡改、校验被绕过等）。
> 本程序涉及键盘钩子权限，保持「不联网、你手动决定升级」更稳妥。
> 代价是升级要自己点两步。

## 从源码构建

无需安装 Visual Studio 或 .NET SDK，系统自带的 C# 编译器即可：

```powershell
.\build.ps1 -Version v1.0.0
```

产物是 `dist\OneKeyTool-v1.0.0-win-x64.zip`——**这一个文件就是全部**，上传到 Release 即可。
包内是 `OneKeyTool.exe` + `config.ini` + `README.md` + `LICENSE`。

`-Version` 是版本号的唯一来源，一处生效于：

- 发布文件名（`OneKeyTool-v1.0.0-win-x64.zip`）
- exe 文件属性（右键 → 属性 → 详细信息 → 文件版本 / 产品版本）
- 设置窗口标题栏、窗口右上角，以及托盘图标的悬停提示

构建脚本会顺带编译并运行 `tests/StateMachineTests.cs` 里的状态机回归用例，
**任何一条不通过都会让构建失败**，因此产物一定是测试通过的版本。

发布时只需把这一个 zip 挂到 Release 上，不需要额外上传校验清单或单独的 exe。

**自动发布**：推送形如 `v1.0.0` 的 tag，GitHub Actions 会自动编译、打包并创建 Release：

```bash
git tag v1.0.0
git push origin v1.0.0
```

## 项目结构

```
OneKeyTool/
├─ src/                       主程序源码（C#，.NET Framework 4.0）
│   ├─ Program.cs             入口
│   ├─ MainForm.cs            可视化配置界面 + 托盘
│   ├─ MacroEngine.cs         识别状态机（纯逻辑，可测试，两种模式共用）
│   ├─ Detector.cs            键盘钩子安装与事件分发（调用 MacroEngine）
│   ├─ Config.cs              配置读写
│   ├─ InputSender.cs         按键注入
│   ├─ ActionRunner.cs        执行动作
│   ├─ AutoStart.cs           开机自启（写用户 Run 项）
│   ├─ Native.cs              Win32 API 声明
│   ├─ BuildInfo.cs           版本信息（默认值；构建时由 build.ps1 生成同名文件覆盖）
│   └─ app.ico                应用与托盘图标资源（多分辨率）
│
├─ tools/                     诊断与辅助工具
│   ├─ KeySpy/                按键抓包分析器
│   ├─ MacroTest/             按键序列回放器（需手动运行）
│   └─ GenerateIcon/          多分辨率应用图标生成器
├─ tests/                     状态机回归测试（build.ps1 每次构建时运行）
│
├─ config.ini                 默认配置模板
├─ build.ps1                  本地构建脚本
└─ .github/workflows/         GitHub Actions 自动发布
```

### 换键盘后失效了？

用 `tools/KeySpy` 重新抓一次包，看那个键的按键序列是否变了。

- 如果只是网址里的特征词不同（比如换成了别的域名），改 `config.ini` 里的 `Signature` 即可。
- 如果按键序列整体不同，改 `src/MacroEngine.cs` 里的状态机（逻辑都在注释里说明白了），
  并在 `tests/StateMachineTests.cs` 里补一条对应用例——构建时会自动跑。

## 常见问题

**Q：为什么按了自定义键，"运行"对话框还是会闪一下？**
检查 `config.ini` 里 `SuppressWindowsKey` 是否为 `true`。

**Q：会影响正常按 Win 键吗？**
会有一个极短的延迟（默认最多 80ms）。可以在 `config.ini` 调整 `WinWaitMs`。

**Q：杀毒软件报毒？**
低级键盘钩子是按键映射、输入法等工具的常规技术，但确实可能触发启发式告警。本项目完全开源，代码就几行，可以自行审阅或从源码编译。

**Q：双击时弹出「Windows 已保护你的电脑」，是病毒吗？**
不是。这是 SmartScreen 对**未做数字签名**的程序的默认提示，任何未签名程序都会这样。
点「更多信息」→「仍要运行」即可，详见[首次运行被拦](#首次运行被-smartscreen-拦了怎么办)。
本程序不联网、不写注册表（除非你主动开启自启），可放心。

**Q：怎么确认自己用的是哪个版本？**
设置窗口右上角、标题栏、托盘图标悬停提示都会显示版本号（如 `v1.0.0`），
与发布文件名、exe 文件属性里的版本一致。反馈问题时直接报这个号即可。
点它还能打开「关于」对话框。

**Q：会在我不知情时联网或替换程序吗？**
不会。程序里没有任何网络代码，也不会自我替换——升级全靠你手动下载覆盖。
「关于」里的「项目主页 / 下载」链接是唯一的外部入口，且只在你点击时才打开浏览器。

**Q：升级后配置文件会丢吗？**
不会。升级只覆盖 `OneKeyTool.exe`，`config.ini` 原样保留。

**Q：目录里多了个 `onekeytool.log`，能删吗？**
能，直接删即可，程序下次启动会重建。它只记运行事件、不记按键内容，
详见上文[关于 `onekeytool.log`](#关于-onekeytoollog)。

**Q：这算破解联想的东西吗？**
不算。没有修改键盘固件，也没有破解任何联想软件——只是在你自己的电脑上拦截一段键盘输入并替换成你想要的动作，属于标准的本机输入自定义。
