# OneKeyTool — 键盘自定义键改造工具

把键盘上那个"一按就打开 `http://oneclick.lenovo.com.cn`"的按键，改成你想要的功能。

> **无需安装** · **不写注册表** · **不改固件** · **随时可退**

---

## 问题背景

不少联想键盘上有个"一键上网"键，按下去会自动打开 `oneclick.lenovo.com.cn`。

但有意思的是：**这跟联想软件没关系**。我用抓包工具实测分析后发现——

> 是**键盘固件自己**在键盘通道上"敲"出了整个网址。

按下那个键时，固件会模拟出这样一串动作：

```
Win↓  R↓  Win↑  R↑          ← 约 12 毫秒内完成，用于唤起"运行"对话框
  ↓ 约 90 毫秒
h t t p : / / o n e c l i c k . l e n o v o . c o m . c n
  ↓ 约 1.1 秒
回车                          ← "运行"对话框据此打开网页
```

**关键特征**：这些字符的输入间隔是 **0.03~15 毫秒**，而人类打字最快也要 **60 毫秒以上**——差了两个数量级。

**这反而是好消息**：走标准键盘通道，意味着**软件层可以完整拦截改写**，不用改固件、不用拆键盘。

## 功能

按那个自定义键，可以做：

| 动作 | 说明 | 参数示例 |
|---|---|---|
| **打开网址** | 按一下就打开你指定的网页 | `https://www.bing.com` |
| **运行程序** | 启动软件、打开文档、打开文件夹 | `C:\Windows\System32\notepad.exe` |
| **发送快捷键** | 模拟按一组快捷键 | `Ctrl+Alt+S`、`Win+Shift+S` |
| **什么都不做** | 只屏蔽原网址 | — |

## 下载使用

1. 到 [Releases](../../releases) 下载 `OneKeyTool-*-win-x64.zip`
2. **解压到任意文件夹**（建议放文档或桌面，不要放 `Program Files`，否则配置写入可能受限）
3. 双击 `OneKeyTool.exe`，程序会最小化到**系统托盘**（右下角）
4. 双击托盘图标打开设置窗口

**环境要求**：Windows 10 / 11（64 位）。系统自带的 .NET Framework 4.0 就够，**无需安装任何运行库**。

### 首次使用：先验证，再启用

程序默认处于**观察模式**——只识别、不拦截，原网址仍会照常打开。

1. **按几次那个自定义键**，看设置窗口里"已触发"计数是否跟着 +1
2. 顺便正常打字、按 Win 键、用 Win+R，确认计数**不会**乱涨
3. 确认没问题后，**取消勾选"观察模式"** → 点"保存并应用"

从此按那个键，原网址不再打开，直接执行你设定的动作。

## 安全性

这个工具需要安装**低级键盘钩子**，所以有几点值得说清楚：

**它不做什么**
- 不联网、不上传任何数据
- 不写注册表、不装驱动、不开机自启（除非你自己设置）
- 不记录你的按键内容
- 不改键盘固件

**它怎么保证不误伤**（已用自动化测试逐项验证）：

| 场景 | 结果 |
|---|---|
| 单独按 Win 键 | 超时后原样放行，开始菜单正常弹出 |
| Win+E 等其他组合键 | 检测到后立即放行 |
| 手动按 Win+R | 按键顺序与宏相反，正确放行 |
| 正常打字（间隔 60ms 以上） | 时序不符，放行 |
| 方向键连按 | 不匹配，放行 |
| 长按 Win 键 | 暂扣达 64 个自动放弃并放行 |

**兜底机制**：万一程序卡死导致键盘异常，用任务管理器结束 `OneKeyTool.exe` 即可，键盘立刻恢复。程序退出后**不留任何痕迹**。

**想彻底停用**：托盘图标右键 → 退出。

## 工作原理

程序安装一个低级键盘钩子（`WH_KEYBOARD_LL`），用**状态机 + 时序特征**识别：

```
看到 Win↓
   ├─ 先"暂扣"不发给系统，开始观察
   ├─ 300ms 内没有后续          → 判定你自己按 Win，原样放行
   └─ 出现 R
        ├─ 250ms 内首字符不是 h   → 不是宏（如你手动 Win+R），放行
        └─ 收到 h → 进入宏收集
             ├─ 校验前缀 "http" 与特征串 "oneclick"
             ├─ 见到回车且特征齐全  → ★ 命中：丢弃整段宏，执行你的动作
             └─ 超时 / 不符        → 放弃拦截，把暂扣的按键原样重放
```

**防递归**：程序注入的按键带 `dwExtraInfo` 魔数标记，钩子无条件忽略，因此"放弃拦截 → 重放"的过程不会自我循环。

## 自定义配置

设置窗口能改大部分选项。想改更细的参数，直接编辑 `config.ini`（和 exe 同目录）：

| 键 | 说明 |
|---|---|
| `Enabled` | 总开关 |
| `ActionType` | `url` / `program` / `hotkey` / `none` |
| `ActionValue` | 动作参数 |
| `DryRun` | 观察模式，`true` 时只识别不拦截 |
| `SuppressWindowsKey` | 是否连 Win 键一起拦（推荐 `true`，避免闪"运行"对话框） |
| `WinWaitMs` | 按 Win 后等待时长。觉得开始菜单变慢了就调小（如 `150`） |

改完点"保存并应用"，或托盘菜单选"重新加载配置"。

## 开机自动启动（可选）

程序**不会**擅自设置自启。想开机自动运行的话：

2. 把 `OneKeyTool.exe` 的**快捷方式**拖进打开的文件夹

取消就把快捷方式删掉。

### 换键盘后失效了？

用 `tools/KeySpy` 重新抓一次包，看那个键的按键序列是否变了。
如果序列不同，改 `src/Detector.cs` 里的状态机即可（逻辑都在注释里说明白了）。

## 常见问题

**Q：为什么按了自定义键，"运行"对话框还是会闪一下？**
检查 `config.ini` 里 `SuppressWindowsKey` 是否为 `true`。

**Q：会影响正常按 Win 键吗？**
会有一个极短的延迟（默认最多 300ms）。觉得慢就把 `WinWaitMs` 改成 `150`。

**Q：杀毒软件报毒？**
低级键盘钩子是按键映射、输入法等工具的常规技术，但确实可能触发启发式告警。本项目完全开源，代码就几行，可以自行审阅或从源码编译。

**Q：这算破解联想的东西吗？**
不算。没有修改键盘固件，也没有破解任何联想软件——只是在你自己的电脑上拦截一段键盘输入并替换成你想要的动作，属于标准的本机输入自定义。
